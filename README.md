# KickOff ⚽

KickOff is a Flutter app for booking football fields. Users browse fields, pick a date and time slot, and send a booking request; admins review and confirm bookings and see total revenue. Backed by Firebase.

## Features

- **Onboarding** – intro slides shown on first launch (remembered with `shared_preferences`)
- **Authentication** – sign up / log in with Firebase Auth
- **Fields** – browse available fields and view field details (live from Firestore)
- **Booking** – book a field for a date and time slot; bookings start as `pending`
- **Calendar** – see booked slots on a calendar (`table_calendar`)
- **My Bookings** – users see their own bookings and status
- **Admin dashboard** – users with `role: admin` see all bookings, confirm pending ones, and get a total revenue summary
- **Profile** – account info, booking history, and avatar upload (Firebase Storage)
- **Store** – product list loaded over HTTP, with a cart

## Tech stack

- Flutter (Dart SDK `>=3.0.0 <4.0.0`)
- Firebase: Core, Auth, Cloud Firestore, Storage
- `get`, `google_fonts`, `introduction_screen`, `smooth_page_indicator`, `table_calendar`, `intl`, `image_picker`, `http`

## Project structure

```
lib/
├── main.dart               # App entry, Firebase init, routes
├── firebase_options.dart   # Generated by FlutterFire CLI
├── constant/               # App constants (colors, cart)
├── data/                   # Firestore models (fields, bookings)
├── images/                 # Intro slide images
├── screen/                 # All screens (home, login, booking, calendar, profile, store...)
└── widget/                 # Shared widgets
```

## Firestore collections

| Collection | Purpose |
|------------|---------|
| `users`    | User profile, `role` (`user` / `admin`), `avatarUrl` |
| `fields`   | Football fields available to book |
| `bookings` | Booking requests with `status` (`pending` / `confirmed`) |

To make an account an admin, set `role` to `admin` on its document in `users`.

## Getting started

1. Install [Flutter](https://docs.flutter.dev/get-started/install).
2. Clone the repo and install packages:
   ```bash
   git clone https://github.com/Chanonwc/kickoff-App.git
   cd kickoff-App
   flutter pub get
   ```
3. Firebase is already configured in `lib/firebase_options.dart`. To use your own Firebase project instead, run:
   ```bash
   flutterfire configure
   ```
   Then enable Email/Password sign-in, Cloud Firestore and Storage in the Firebase console.
4. Run the app:
   ```bash
   flutter run
   ```
